# Electrochemistry Python

A collection of Python tools for electrochemistry, scientific computing, and data analysis.

## Goals

This repository aims to provide open-source Python tools for:

- Electrochemical calculations
- Cyclic voltammetry (CV) analysis
- Linear sweep voltammetry (LSV) analysis
- Electrochemical impedance spectroscopy (EIS)
- Tafel analysis
- Current density calculations
- Nernst equation calculations
- Faraday's law calculations
- CO₂ reduction research
- Nitrate reduction research

## Planned Modules

### Calculators

- Nernst Equation
- Faraday's Law
- Current Density
- Overpotential
- Tafel Slope

### Data Analysis

- CSV Reader
- CV Plotter
- LSV Plotter
- EIS Plotter

### Future Plans

- Machine Learning for Electrochemistry
- Automated Electrochemical Data Processing
- Research Notebook Examples
